## 📝 Documentation Standards

### File Naming
- Use descriptive, lowercase names with hyphens for spaces
- Add `.md` extension for markdown files
- Group related docs in subdirectories

### Organization Principles
- **Topic-based folders** for related documentation
- **README.md files** in each folder for navigation
- **Clear cross-references** between related documents
